I re-wrote this from the ground up. There is still a lot of work that needs to be done, but they are all future upgrades that will come out in time. The core plugins is intact and operational.

When you type /fashionreport or /fr, a window will open up that display the weekly fashion report. If it is in red, it is not updated for the week. To be updated, one person with the mod needs to talk to Masked Rose. Once someone does, the automatically polling of the database will update everyone. Polling happens on Tuesdays (new week) and Fridays (Dyes can be discovered). Once information is updated, polling shuts down until the next time period arrives.

Clicking on a theme will allow you to see all the items for that slot that will fit the theme. I still need to code the icons being added (crafting, Wolf Marks, etc ...) but they are in the code ready to go visually. Also there an ABOUT section that goes into the details of how Fashion Report works. I have been doing this for years, and I could not find any detailed description of how the point system works. Some people have a general idea, but they don't know how or why. Like they know points start at 68 if you have 4 armor themed slots but 70 if you have 3 armor themed slot and 1 accessory. Most people could not tell you exactly what all the stamps mean, specifically the light blue one. So I took the time to really find out and this plugin is a result of those efforts. For the longest time I could look at someone and tell them how Masked Rose would judge them in points. A lot of people loved that, but I can't always be there in Gold Saucer doing that so here comes this plugin.

Another feature of this plugin is that when a player does get judged by Masked Rose, the data is saved to the database in a table that self wipes itself each week. The data is only the information collected from fashioncheck addon, which is your itemids, your glamourids, stains, etc ... this information is very helpful in finding the dyes faster. When a lot of this data is collected and analyzed together, you can narrow down and eliminate most dyes fast, even finding the dyes. Using this system manually, I was able to beat the group over at Reddit by hours. I was able to discover the dyes in under an hour by myself. Instead of one person doing it with a lot of free accounts, the idea is that all information is shared and viewed by all to get the dye information faster. It will also add any new fashion pieces that were not in the database, so it is self growing.

The dye window hasn't been built yet, just the information gathering part. The Dye window will come in a future update, where you can see the fyes attempted for each slot and the results. Also in a future update, there will be a Dye Window for knowing dye groups (it's based on IconId surprisingly enough, there are 2 for each color and 9 color groups) and where you can acquire those dyes.

Lastly, this plugin doesn't just populate the other players who use the plugin, it also populates my Discord Bot which generates Fashion Reports automatically each week. You can use the /fashionreport command to get the current week or use the week option to pick a random week from the past. The report generates the image right in Discord for you each time.
